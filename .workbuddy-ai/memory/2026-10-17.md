# 2026-10-17

## 食有灵 FOOD SOUL — 中国美食 AI 人格站（从零搭建）

**技术栈**：React 18 + TS + Vite 5 + React Router 6；CSS 变量设计系统，无 UI 框架。
AI 服务层用 Vite 中间件（`server/api.ts`）同时服务 dev 与 preview，避免额外后端进程。

**关键决策**
- Hero 用暖奶油底（#F7F1E7）作为暗色站的「浅色岛」，其余区块 #0B0B0D，用 28px 圆角暗色 sheet 衔接；导航三态：clear / is-light-solid / is-solid。
- 星环三层结构实现「轨道旋转 + 文字正向」：`.orbit-rotor`(θ) → `.orbit-slot`(rotate a + translate r + rotate -a) → `.orbit-counter`(-θ)。悬停/聚焦用 `animation-play-state: paused` 同时暂停，位置不丢。
- 美食图片无法从图库获取（Wikipedia/Unsplash API 均不可用），改用 `FoodPortrait` 组件：色系渐变 + 盘沿 + 蒸汽 + 颗粒 + 大号 emoji 作为「盘中肖像」。真实图片可直接替换该组件。
- 角色人格配置集中在 `src/data/characters.ts`（17 位，含独立 systemPrompt 模板），组件不硬编码人设。
- 推荐为「规则筛选 + 打分 → AI 只写理由」，绝不凭空生成菜品；口味用关键词映射（麻辣→麻/辣 等）避免推荐跑偏。
- 无 `ZHIPU_API_KEY` 时全部走演示模式，并在 UI 明确标注（demo-flag / chat-notice / 演示菜谱）。

**踩坑**
- 圆盘用 `padding: 11%` 会按父容器宽度解析（不是自身宽度），导致圆盘被拉成椭圆 → 改为 `calc(var(--disc) * 0.11)`。
- NavLink 对 `/#hash` 在首页会全部命中 isActive → 改为按 pathname+hash 手动判定。
- Playwright 点击旋转中的节点会因「element is not stable」超时 → 用坐标点击；真人悬停即暂停，不受影响。

**未完成**：用户登录、社区数据库持久化（现为 localStorage）、真实菜谱库。
