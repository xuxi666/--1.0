## 转场重构：真实目标页作为圆形揭示层（去掉纯色圆与色彩浸润）

- **需求**：把原来「纯色圆形扩散 + 色彩浸润 + 结束后新页面再入场」改成——点击瞬间圆形里透出的就是**目标页本身**（背景 / 角色 / 名称 / 介绍 / 聊天结构），圆外仍是首页；用 `clip-path: circle()` 扩张，350–500ms（默认 420ms）、缓动 `cubic-bezier(0.16, 1, 0.3, 1)`、点击即开始扩张无停顿；半径按点击点到最远角计算、四角全覆盖；扩张完成 → 切路由 → 移除揭示层必须**无缝无闪屏**；预览稳定（不随机、不闪烁、不布局跳动、不阻塞聊天加载）；返回首页**取消圆形转场**直接跳转且无残留、可再次点击；防连点、桌面手机都可用、reduced-motion 直接跳转、动画结束/卸载/路由变化都清理定时器与临时 DOM。
- **关键决策**：
  - Provider 新增 `renderPreview?: (to: string) => ReactNode`，由 `App.tsx` 注入 `<Routes location={to}>` 渲染 `/cuisines/:cuisineId` 与 `/tastes/:tasteId` 的真实页面组件——转场层与页面组件之间没有循环 import（Provider 不 import 页面，页面只 import hook）。

## 转场丝滑化：放弃 clip-path，改合成器 transform + 逆缩放（取消明显停顿）

- **反馈**：上一版真页面圆形揭示「有明显停顿、不够丝滑」，要求点击即动、全程圆边在动、尾声不长时间静止，返回首页仍直接跳转。
- **实测根因（CDP 时间线 / 长任务 / 截屏帧）**：
  1. 旧实现点击时同步挂载真实页 → 首个长任务约 204ms，动画起点距点击约 225ms（观感上的「先卡一下再开始」）。
  2. `clip-path` 每帧改变圆半径都触发整层重绘 → 主线程出现 153ms / 99ms 的帧空档，圆边一跳一跳。
  3. 缓动 `cubic-bezier(0.16, 1, 0.3, 1)` 在 158ms 就走到 progress 0.929（圆已铺满），剩下 260ms 画面完全不动（尾声静止）。
- **新实现（`CircularTransition.tsx` 重写 + `transition.css` 同步）**：
  - 点击处理函数里**同步用原生 DOM** 建 `.circular-transition` 壳 + `.circular-transition__reveal` 圆形取景框（`border-radius: 50% + overflow: hidden`）并立刻 `animate()`；React 只用 `createPortal` 把真实页渲染进舞台 `.circular-transition__preview`——首帧不再等 React 挂载。
  - 扩张 = 容器 `scale(s0 → 1)`（2 个关键帧）+ 舞台反向 `scale`；只动 `transform`，走合成器，主线程挂载页面 / 切路由都不影响圆边。
  - **逆缩放不能用「1/s0 线性补间到 1」**（倒数曲线是双曲线，实测内容被放大 4.7×）。用 `cubicBezier()` / `invertEase()` / `counterScaleKeyframes(startScale)` 生成约 70 个线性关键帧（每段半径增长 ≤4%，插值误差 <0.05%），实测 150ms 时 reveal 0.568 / stage 1.763，圆内页面 1:1 清晰。
  - 缓动改为 `cubic-bezier(0.25, 0.35, 0.55, 1)`：点击后 1–2 帧内起动画，82% 时长走完约 97% 半径，没有「瞬间铺满 + 长尾巴」。
  - 首帧先画「小圆 + 主题柔光底盘」（`radial-gradient` 用 `--t-glow` 叠在主题背景上，`afterFirstPaint()`：rAF → `setTimeout 0`），再挂真实页并 `opacity` 0→1 淡入（`STAGE_FADE_MS=200`，按剩余时间自适应到 `CONTENT_FADE_BY_MS≈361ms` 前完成）。
  - 扩张走完（`grow.finished`）才 `markWorldArrival` + `navigate`；真实页挂载完成即 `pointer-events: none`（交互不必等揭示层摘除）→ 再等 3 帧首绘 → 直接移除，无 60ms 固定等待。
  - 非聊天目标兜底改为 `.circular-transition__reveal--color` 主题渐变圆（原 `.circular-transition__circle` 移除），扩张完 → navigate → 2×rAF → 260ms 淡出。
  - 清理：`finish(runId)` 自增 `runIdRef` 作废后续 async、清 6s 看门狗、先摘壳再 `cancel()` 全部 Animation、移除 `is-transitioning`、`setOverlay(null)`/`setActive(false)`。
- **实测（dev 5173，1440×900，dpr1，川菜；`node scripts/tmp-smooth-probe.mjs`）**：
  - `overlayAt=25–39ms`（旧 204ms）、动画 `startTime` 距点击 46ms、`duration=420`、`easing=cubic-bezier(0.25, 0.35, 0.55, 1)`、关键帧仅 `transform`、首帧 `scale(0.0591)` → 末帧 `scale(1)`；
  - 内容首个采样 `@276ms`（挂载 longtask 约 162–172ms，仍在扩张中）、`navT≈542–631ms`（含挂载阻塞后的探测延迟）、`removedAt≈710ms`；
  - 冻结 150ms 截图：圆内粤菜页 1:1 清晰（标题 / 介绍 / 按钮 / AI 聊天区 / GLM 在线），圆外首页正常，圆边光滑；
  - 预览 vs 落地几何：标题 x 431.4 vs 432、容器宽 1282.5 vs 1280（误差 <1.5px，来自逆缩放插值）；新 ui-check 采样 `|revealScale×stageScale−1|` 最佳 7/7 帧，最差 0.0013。
